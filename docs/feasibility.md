# Feasibility & Potential Impact

## Beyond the Hackathon

### What Works Today
- Pollar SDK: production-ready, mainnet available
- Paystack: production gateway, real money movement
- Stellar USDC: $10B+ daily volume, Circle-backed
- Stereum BOB ramp: live on Pollar

### What Needs Building
- Liquidity desk for Paystack → USDC conversion
- Agent onboarding and KYC process
- Mobile app (React Native or PWA)
- Multi-country expansion (Kenya, Ghana, Mexico)

### Revenue Model
- Agent fee: 0.8-1.5% per corridor
- Platform fee: 0.2-0.5% per corridor
- At $1M monthly volume: $10K-20K revenue
- At $10M monthly volume: $100K-200K revenue

### Scalability
The agent network model scales to any corridor:
- Nigeria ↔ Mexico (SPEI off-ramp)
- Kenya ↔ Colombia (BreB off-ramp)
- Ghana ↔ Peru (SEP-24 anchors)
- South Africa ↔ Argentina (bank transfer)

### Competitive Advantage
- **Agent network**: Hard to replicate, grows with volume
- **Stellar**: Fast, cheap, non-custodial
- **Pollar**: Already has the infrastructure
- **Story**: Two parallel-FX economies — unique positioning

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Agent fraud | Collateral + reputation slashing |
| FX volatility | Real-time quotes, short corridor windows |
| Regulatory | Non-custodial, no custody of user funds |
| Liquidity | Start with sandbox, grow organically |
| UX complexity | Pollar abstracts crypto, social login |

## Impact Metrics

If successful:
- **Financial inclusion**: Bank-free cross-border payments
- **Cost reduction**: 2-3% vs 5-10% traditional
- **Speed**: 5-10 min vs 3-5 days
- **Agent income**: Earn fees for holding float
- **Remittance volume**: $600B/year global, Africa↔LatAm underserved
